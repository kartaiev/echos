# A Mode is modelled as Mode Variants, one per Melos

The obvious model, "one Mode = one scale", is wrong for Byzantine chant: the same Mode can have a different Base and Genus depending on the Melos (e.g. Plagal 2nd is Soft Chromatic in Heirmologic melos and Hard Chromatic in Sticheraric; 3rd Mode can be Enharmonic or Diatonic). We therefore model each Mode as a set of Mode Variants keyed by Melos, each with its own Base, Genus, Dominant Degrees, Cadences and Intonation. The first release fills Heirmologic and Sticheraric variants; Papadic comes later without a model change.
