# Mode Variant data follows Melling, mapped onto Heirmologic and Sticheraric

The first source we found that gives Genus, Base and Dominant Degrees for all eight Modes in one place is David J. Melling, "Reading Psalmodia" (2000), §9. Melling does not always split melodies by Melos: for several Modes he separates "Irmic and short Sticheric" melodies from "slow Sticheric" ones instead. We map the first group to Heirmologic and the second to Sticheraric. This mapping gives Plagal 2nd Heirmologic in Soft Chromatic and Plagal 2nd Sticheraric in Hard Chromatic, which agrees with ADR-0002. Where Melling offers two Bases ("Vu or Di", "Pa or Ke", "Zo or Zo'"), we take the first one he lists. Where he gives one mode for both kinds of melody (3rd, Plagal 4th), both Melos get the same Mode Variant. Teachers disagree on several of these, most of all on the 2nd and Plagal 2nd. So every Mode Variant stays `unreviewed` (ADR-0001) until a reviewer signs it off, and changing any of these choices is a data change only.
