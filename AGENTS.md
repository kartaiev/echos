# Echos

A free, open-source practice companion for Byzantine chant (scales, modes, ison, tempo). Domain language lives in `CONTEXT.md`; decisions in `docs/adr/`.

## Agent skills

### Issue tracker

Issues and specs live in GitHub Issues for `kartaiev/echos`, managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
